# 화면 설계 — 세션 화면(`/admin/sessions`)과 대시보드 우회 탐지 카드

Plan 4 Task 18 산출물. `frontend-design` 스킬로 `docs/design/direction.md`(고성능 HMI 관제 콘솔)와 `screens/mcp.md`(대시보드·목록의 밀도와 표 규칙)를 원격 접속 감사 기록에 적용했습니다. 문구는 `design:ux-copy`(해요체, `web/src/copy/ko.ts`의 `sessions`·`tamper`), React 구조는 `vercel-react-best-practices`, 자체 점검은 `audit-as-ux-eng`·`audit-as-a11y-eng`. 창 폭은 사용자 결정(C4)대로 1920·1280·1024·800·640(640×600)에서 확인하고, 휴대폰 배치는 만들지 않습니다.

## 1. 일

- **누가:** 로그인한 MCP 개발자와 Admin, 두 채널 모두(`view_session_history`, V31 — 로컬 전용이 아님).
- **첫째 일:** "지금 누가 붙어 있고, 최근 누가 어디서 들어왔으며, 들어오면서 고지를 확인했나"에 답하는 것. 둘째 일은 이상한 것(처음 보는 IP·기기, 확인하지 않은 고지, 로그인 실패, 멈춘 수집기)을 훑어서 찾는 것.
- **이 화면은 감사 기록입니다.** 표는 촘촘하고 움직이지 않으며, 강조는 "다시 봐야 할 사실"에만 씁니다.

## 2. 한 가지 대담함

화면 전체가 중립입니다(상태 hue는 MCP 상태 전용). 이 화면에서 눈길을 끄는 것은 **확인하지 않은 고지 한 가지**뿐이고, 보드의 세션 카드와 같은 모양(삼각 경고 아이콘 + `state-suspect` 계열 글자 + "확인 안 함")을 씁니다. 처음 보는 IP·기기는 경고가 아니라 "한 번 더 볼 사실"이라 hue 없는 테두리 칩(아이콘 + 글자)으로 둡니다. 둘 다 색만으로 구분하지 않습니다(WCAG 1.4.1).

## 3. 배치

```
세션                                                                   ← h1 text-xl
┌ 현재 세션 ────────────────────────────────────────────────────────────┐
│ [SessionCard hong ………………………]  [SessionCard kim ……………………]           │ ← 보드에 있는 세션: 보드와 같은 카드
│ ┌ CORP\lee   ⏏ 연결 끊김   LEE-PC   10.0.3.40   연결 끊긴 시각 … ┐    │ ← 보드에 없는 세션(끊김·로그온 전): 상태 줄
└────────────────────────────────────────────────────────────────────────┘
기록 기간 [최근 1일][최근 7일][최근 30일][최근 90일]                    ← aria-pressed 묶음, URL ?days=
┌ 접속 이력 ─────────────────────────────────────────────────────────────┐
│ 접속 시각 │ 사용자 │ 클라이언트 PC │ IP 주소 │ 종류 │ 종료 │ 사전 고지    │
│ 2026-…    │CORP\hong│ HONG-PC [🖥처음 보는 기기] │ 10.0.3.21 [🌐처음 보는 IP] │ 다시 연결 │ 접속 중 │ ⚠ 확인 안 함 │
│                              host.corp (PTR, 작은 글씨)                                │
└──────────────────────────────────────────────── [더 보기] ─────────────┘
┌ 로그인 실패 ───────────────────────────────────────────────────────────┐
│ 시각 │ 사용자 │ IP 주소 │ 워크스테이션 │ 로그온 유형 │ 상태 코드        │
└────────────────────────────────────────────────────────────────────────┘
┌ 수집 상태 ─────────────────────────────────────────────────────────────┐
│ 수집기(모노 이름) │ ✓ 수집 중 / ⊘ 수집 중단: access denied │ 바뀐 시각     │
└────────────────────────────────────────────────────────────────────────┘
```

- 네 구역은 `section[aria-labelledby]` + h2, 위에서 아래로 한 열(표가 넓어 2열을 쓰지 않음). 모든 내용 왼쪽 정렬.
- **기간 선택**은 이력·실패 두 구역에만 걸리므로 현재 세션 아래, 그 두 구역 바로 위에 둡니다(현재 세션은 기간과 무관). 묶음 이름 "기록 기간". 기본 7일은 URL에 쓰지 않습니다(`/admin/sessions`), 다른 값은 `?days=30`. 기간을 바꾸는 동안 이전 기간의 표를 60% 불투명도로 유지(`aria-busy`, MCP 이력 탭과 같은 규칙, 깜박임 없음).
- **현재 세션 카드 격자:** `repeat(auto-fill, minmax(min(100%, 28rem), 1fr))`. 640에서 한 열. 보드 세션(BoardStore, 실시간 경과·유휴·고지)은 `SessionCard` 그대로, 보드에 없는 세션(끊김·로그온 전, 또는 보드가 아직 모르는 세션)은 한 줄짜리 상태 줄(`dl`: 사용자, 상태 아이콘 + 글자, 클라이언트 PC, IP 모노, 접속 시각 또는 연결 끊긴 시각). 상태 줄 아이콘은 중립 잉크(끊김 = 플러그 빠짐, 로그온 전 = 로그인, 사용 중 = 모니터, 잠김 = 자물쇠).
- **표 밀도:** 관리 표와 같은 36px 행(`text-sm`), 머리 `text-xs` muted. 시각은 KST `YYYY-MM-DD HH:mm:ss` `tabular-nums`. IP·PTR·수집기 이름·상태 코드는 모노(복사·대조하는 기계 값). 사용자는 `DOMAIN\user`. 종료 열은 시각 + 아래 줄에 사유(작은 muted), 진행 중이면 "접속 중".
- **좁은 창:** 페이지는 옆으로 스크롤하지 않고 표만 자기 틀(`overflow-x-auto`) 안에서 스크롤합니다. 첫 열(접속 시각)이 행의 맥락이라 `th scope=row`.
- **더 보기:** 다음 페이지(`before_id`)를 이어 붙입니다. 불러오는 동안 버튼 `aria-busy`(포커스 유지), 더 없으면 버튼이 사라집니다. 실패하면 버튼 옆 `role=alert` 한 줄, 버튼은 그대로(다시 시도).

## 4. 빈 상태·로딩·오류

| 구역 | 로딩 | 빈 상태 | 오류 |
|---|---|---|---|
| 현재 세션 | 카드 높이 스켈레톤 + `role=status` "불러오는 중…" | 첫 수집 전(`ready=false`): `board.sessionsNotReady` / 수집 후 없음: "지금 접속한 세션이 없어요." | `role=alert` "불러오지 못했어요. 새로 고친 뒤 다시 시도하세요." |
| 접속 이력 | 행 높이 스켈레톤 3줄 | "이 기간에는 접속 기록이 없어요." | 같은 오류 문장 |
| 로그인 실패 | (이력과 같은 요청) | "이 기간에는 로그인 실패가 없어요." | (이력과 같음) |
| 수집 상태 | 스켈레톤 2줄 | "켜진 수집기가 없어요." | 같은 오류 문장 |

빈 상태는 "무엇이 없고 왜인지"(기간)만 말합니다. 이 화면에서 사용자가 할 다음 행동은 기간을 넓히는 것뿐이고, 그 버튼이 바로 위에 있습니다.

## 5. 대시보드 "우회 탐지 이벤트" 카드

- `PlannedFeature planned_logs`를 대체합니다. "로그인 실패 추이"는 그대로 `PlannedFeature`(Plan 5).
- `GET /api/tamper/recent` 최근 10개(새것 위). 줄마다 방패 경고 아이콘(`state-suspect`, 우회 탐지는 늘 "다시 봐야 할 일") + 이벤트 이름(`copy.tamper.events`, 굵게) + KST 시각(muted, `tabular-nums`) + 요약(사용자, "세션 N", 사용자·세션이 없으면 경로·파일·레지스트리 값 이름을 모노로).
- SSE `tamper`(로그인한 스트림에만 옴) → 캐시 맨 앞에 넣기(최대 50). 스트림이 다시 연결되면 놓친 것이 있을 수 있어 다시 불러옵니다. 새 줄에 진입 애니메이션 없음(목록·표 규칙).
- 비면 "최근 우회 탐지 이벤트가 없어요." 로딩·오류는 활동 카드와 같은 모양.

## 7. 접근성

- 랜드마크: 셸의 `nav`·`main` → h1 → 구역 h2. 표는 h2로 이름이 붙습니다(`aria-labelledby`).
- 기간 묶음: `role=group aria-label="기록 기간"`, 버튼 `aria-pressed`.
- 배지·고지 상태: 아이콘은 `aria-hidden`, 뜻은 글자가 전합니다.
- 더 보기: `aria-busy`로 포커스를 지킵니다. 붙은 행은 읽지 않습니다(표가 바뀐 것은 사용자가 누른 결과).
- 내비의 "세션"은 이제 링크입니다(로그인하지 않으면 셸 자체가 로그인으로 보냄, 정책상 이유 `login`).

고친 것:
- 카드 격자 최소 28rem에서 1280 폭에 카드가 반쪽만 차지하고 접속 시각이 잘림 → 최소 36rem(1280에서 한 장이 전체 폭, 1920에서 두 열).
- 끊긴 세션 상태 줄의 긴 `DOMAIN\user`가 10rem 칸에서 잘림 → 칸 격자 대신 내용 폭으로 줄바꿈(flex-wrap).
- 320 CSS px(400% 확대)에서 기간 버튼 4개가 한 줄을 고집해 69px 가로 스크롤 → 버튼 묶음 줄바꿈.
- 컨트롤이 없는 넓은 표가 좁은 창에서 키보드로는 옆으로 스크롤할 수 없음(a11y 점검) → 표 스크롤 틀에 `tabIndex=0` + 구역 이름(`role=group`, h2로 이름).
- "더 보기"로 마지막 페이지를 받으면 버튼이 사라져 포커스가 `<body>`로 떨어짐(a11y 점검) → 늘어난 표의 틀로 포커스 이동.
