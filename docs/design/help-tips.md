# 도움말 팁 목록 (InfoTip)

화면의 버튼·라벨·배지·상태 가운데 처음 쓰는 운영자가 뜻을 짐작하기 어려운 것에 “i” 도움말을 붙였습니다. 저장·취소·로그아웃·이메일처럼 누구나 아는 것은 뺐습니다. 이 문서는 목록과 근거이고, **실제 문구는 `web/src/copy/ko.ts`의 `help`**(일부는 기존 `channel.localHint`·`logs.keywordHint`·`logs.cmdLimitHelp`)에 있습니다. 문구를 바꾸면 이 표의 한 줄 설명도 함께 고칩니다.

## 컴포넌트

`web/src/components/app/InfoTip.tsx` — Radix Popover 위의 토글팁.

- 라벨 옆(라벨 **밖**)의 24px 버튼과 14px `Info` 아이콘. 이름은 `<라벨> 설명`(WCAG 2.5.3), `type="button"`이라 폼을 제출하지 않고, 라벨 밖이라 입력란의 이름은 라벨 그대로입니다.
- 마우스를 0.3초 올리면 열리고, 키보드 초점을 받아도 열립니다. 클릭·탭은 열어서 고정합니다(WebView2·터치에는 호버가 없음). 다시 클릭, Escape, 바깥 클릭, 초점 이동으로 닫힙니다. 팁 위로 마우스를 옮겨도 닫히지 않습니다(WCAG 1.4.13).
- 초점은 팁 안으로 옮기지 않습니다. 버튼은 `aria-expanded`, 열렸을 때 `aria-controls`, 그리고 `aria-describedby`로 늘 도움말을 가리킵니다(닫혀 있으면 `<body>`의 숨은 사본, 열리면 `role="tooltip"`인 팁 자체).
- 팁은 최대 22rem(좁은 창에서는 창 너비 − 1rem), 창 가장자리 8px 안쪽에 머무르고(Radix 충돌 회피), 넘치면 창 높이 안에서 스크롤합니다. 한국어는 `break-keep`으로 낱말 단위 줄바꿈.
- 열고 닫을 때 페이드(`--motion-fast`)만 쓰고, 동작 줄이기 설정에서는 전역 규칙이 없앱니다(`data-anim="fade"`).
- 목록형 도움말(`{ lead, items }`)은 용어–설명 목록으로 보여 주고, 화면 읽기 프로그램에는 한 줄로 읽힙니다.
- 이유가 있어 못 쓰는 컨트롤은 기존 `WithReason` 툴팁을 그대로 씁니다(팁을 겹쳐 달지 않음). 아이콘만 있는 버튼(작은 조치 버튼, 아이콘 레일)도 기존 툴팁이 이름을 보여 줍니다.
- 표 머리글에 팁을 달면 `th`에 `aria-label`로 라벨만 남겨, 셀마다 “… 설명”이 읽히지 않게 합니다. `legend` 안에 팁을 달면 `fieldset`을 `aria-labelledby`로 legend 글자에만 연결합니다.
